# Rick & Morty iOS App

## Descripción
Aplicación iOS que consume la API de Rick & Morty para mostrar personajes, con sistema de favoritos y persistencia local.

## Tecnologías
- Swift
- UIKit + SwiftUI
- Core Data / SwiftData
- MVVM Clean Arquitecture

## API
https://rickandmortyapi.com/

## Funcionalidades
- Listado de personajes con paginación
- Búsqueda por nombre
- Vista de detalle (SwiftUI)
- Sistema de favoritos
- Persistencia local
- Manejo de conexión a internet

## Cómo ejecutar
1. Clonar el repositorio
2. Abrir el proyecto en Xcode
3. Ejecutar en simulador o dispositivo
